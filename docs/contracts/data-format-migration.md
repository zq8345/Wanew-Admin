# 数据格式迁移：验收清单

**发起方**：wanew-admin · 仓 `zq8345/Wanew-Admin` · 路径 `docs/contracts/data-format-migration.md`
**读者**：下一个要改某个字段"存什么形态"的人（官网窗口、多语言窗口、以及未来的我）
**来源**：2026-07-28 把产品的 `form` 从显示名迁成 key。迁移本身是对的、验收五项全过、生产 curl 全对，
**而 admin 在那之后完全写不进去了** —— 68 个产品保存全被拒。下面每一条都是那次买来的。

---

## 一句话

> **迁移不会弄坏代码，它只是让代码里的假设第一次失败。**
> 所以要枚举的不是"谁读这个字段"，是"**谁隐含地假设了它的旧形态**"。

---

## 一、验收必须包含的三条

### ① 每一个**写入方**在新格式下仍能写入 —— 而且**真写一次**，不是读代码

那次的五项验收全是读侧（数据对不对、官网读得对不对、生产页面对不对），**没有一项验"写入方还能不能写"**。

### ② 🔴 读侧全绿**不构成任何证据**

**读侧看到的数据是完好的** —— 迁移把数据改对了，所以每一个读检查都会放行。
**"读得对而写不进去"是一个所有读侧检查都会通过的状态。**

### ③ 枚举的对象是"谁假设了旧形态"，不是"谁引用了这个字段名"

```
正向：搜字段名            rg "\.form\b|form ===|form:|FORMS"
反向：搜【旧形态的字面值】  rg "Cables|Mounts &(amp;)? ?Brackets|…"
      ⚠️ 含转义形态：HTML 里 & 存成 &amp;，只搜原文会得到假的 0
```

**两个集合不重合。** 那次前端有一份硬编码的显示名常量 —— **它是消费方，但它的代码里没有 `form` 这个词**，正向搜永远搜不到它。

---

## 二、那次实际漏掉了几个（用来校准"我找完了没有"）

先找到 2 个就动手了，实际 6 个：

| # | 消费方 | 漏掉的后果 |
|---|---|---|
| 1 | 删品类守卫 | 删一个有 33 个产品的品类被**沉默放行** |
| 2 | 官网 integrity-check 计数 | 🔴 **检查仍然 PASS**，但把每个品类的产品数打印成 0 —— 而那行字面写着 `delete blocked while >0`。**它印出来的正好是"可以删"的那个数字。**（孤儿判定没坏，因为它收两种取值；坏的只有计数） |
| 3 | **保存产品校验** | **68/68 产品无法保存** |
| 4 | 批量改形态校验 | 批量操作失效 |
| 5 | 仪表盘 / 品类页计数 + **孤儿判定** | **全部产品被判成孤儿** |
| 6 | **前端硬编码显示名常量** | 编辑页回填静默变空 → 保存抹掉该字段 |

> ⚠️ **这六个在迁移之前全都是对的。** 它们一直假设"这个值只有一种取值"，
> **而那个假设在单一取值的世界里从来不会失败。**

## 三、修法：收成一个归一化函数，别在每处各写一遍

```ts
// src/publish.ts
export const normForm = (v, forms) => { /* 收 key 与显示名两者，一律返回 key，认不出返回 null */ };
```

**三条不写会出事的**：

1. **收两种，不是放松校验** —— 第三种取值仍然拒。
2. 🔴 **落盘一律归一化成新形态** —— 只"收下"而按原样存，**数据会重新分叉成两种取值**，等于把刚做完的迁移慢慢撤销。
3. 🔴 **不假设原子性** —— 迁移期两种取值会同时存在（分批、回滚、半途失败都会造成）。
   **守卫的正确性不该依赖另一个操作的原子性。**

**收成一个函数的真正好处**：**"这个值还有几个消费方"这个问题只需要被回答一次。**

---

## 四、迁移脚本本身的四条（`scripts/migrate-form-to-key.mjs` 是范本）

1. **本地 node 跑，不在 Worker 里** —— 一次性任务不该被运行时的限制塑形。
2. **验收比【集合】不比【计数】** —— 两个桶产品数恰好相同时，交换后每个计数都不变。
3. **基线在被测之外** —— 迁移前、由无关代码算出、**连真源 commit 一起提交进 git**。
   迁移脚本自己报的"改前/改后"是自己出题又自己打分。
4. **认不出的值中止，不猜** —— 猜出来的是孤儿，而孤儿要等下一次构建才报，那时离迁移已经很远。
5. **一个 commit** ⇒ 回滚是 `git revert` 一条命令，不是一次考古。
